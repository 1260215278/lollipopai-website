# 发行中心 · 收款管理 — 前端对接契约

> 域：**发行中心控制台**（`/publisher/**`，走 publisher token，header `token`，需 `@PublisherLogin`）
> 后端分支：`test`；主体为 bug21 已实现，本次（20260701）补齐「公司名服务端自动带入 + 空态可取公司名」两处差异。
> 涉及代码：`PublisherPayoutAccountController` / `PublisherPayoutAccountService(Impl)` / `PayoutAccountVO` / `PayoutAccountRequest`
> **无 DDL 变更**——沿用 `publisher_payout_account` 表（bug21）。

对应设计稿 4 态：未添加(空态) / 新增 / 修改 / 已绑定展示。

单账号模型：一个发行方同时只保有 **一条** 有效收款账号。修改为**自助**（保留 update 接口）。

---

## 1. `GET /publisher/payout/account` 查询收款账号

未绑定也返回对象（`bound=false`），且 `companyName` 始终按入驻资料回填 —— 供「新增收款账户」表单「自动带入」公司名。

### 响应

```jsonc
{
  "code": 0, "msg": "success",
  "data": {
    "bound": true,                         // false=未添加(空态); true=已绑定(展示/编辑)
    "id": 12,
    "companyName": "北京星河文化传媒有限公司", // 服务端按 publisher_apply.company_name 自动带入，前端只读
    "accountNo": "6225XXXX0000",           // 银行账号；未绑定时 null
    "bank": "中国银行",                     // 开户银行；未绑定时 null
    "branch": "深圳支行",                   // 开户支行(选填)；未绑定时 null
    "accountHolder": null,                  // 账户名(选填，本表单不采集)
    "currency": "USD",                      // 结算币种，缺省 USD；未绑定时 null
    "status": 1,                            // 0禁用 1启用；未绑定时 null
    "createTime": "2026-07-01 12:00:00",
    "updateTime": "2026-07-01 12:00:00"
  }
}
```

- 空态：`bound=false`，前端展示「尚未添加收款账户」+ 立即添加；点开表单用 `companyName` 回填只读的「公司名称」。
- 已绑定：`bound=true`，直接渲染展示页；点「修改」进编辑页，字段回填 `accountNo/bank/branch`。

## 2. `POST /publisher/payout/account` 新增收款账号

### 请求体

```jsonc
{
  "accountNo": "6225XXXX0000",   // 必填，≤64
  "bank": "中国银行",             // 必填(开户银行)，≤128
  "branch": "深圳支行",           // 选填(开户支行)，≤255
  "accountHolder": null,          // 选填，≤128
  "currency": "USD"               // 选填，缺省 USD，≤8
}
```

> **公司名称不需要前端传**：即使传了 `companyName` 后端也忽略，一律以入驻资料 `publisher_apply.company_name` 为准（防止与已实名主体不一致）。

### 响应 / 错误

- 成功：`{ "code":0, "data": <账号实体> }`
- `403315`：已存在收款账号，请改用「更新」接口。

---

## 3. `POST /publisher/payout/account/update` 修改收款账号

请求体同 §2。公司名同样服务端自动带入、忽略前端传值。

- 成功：`{ "code":0, "data": <账号实体> }`
- `403316`：收款账号不存在（应先新增）。

---

## 4. 字段 ↔ 设计稿映射

| 设计稿字段 | 接口字段 | 说明 |
|---|---|---|
| 公司名称（自动带入，只读） | `companyName` | 服务端回填，前端 disabled 展示 |
| 银行账号 * | `accountNo` | 必填 |
| 开户银行 * | `bank` | 必填 |
| 支行名称（选填） | `branch` | 选填 |
| —（本表单未采集） | `accountHolder` / `currency` | 内部字段，前端不传 |

## 5. 联调注意

- 「银行账号」设计稿示例里出现了中文测试值；正式对公账号一般为纯数字，如需强校验可后端再加 `@Pattern`（当前仅 NotBlank + 长度）。
- 展示币种：结算体系为 USD，收款账号 `currency` 默认 USD；设计稿显示 ¥ 属展示层，另议。
- 修改后端已支持自助（对应「修改」按钮 + 编辑页）；设计稿里「如需修改请联系平台客服」仅作提示文案。
