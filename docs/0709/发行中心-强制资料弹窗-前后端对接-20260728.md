# 发行中心 · 强制完善头像/英文昵称弹窗

- 设计稿：Figma `16590:1513` ProfileSetupModal
- 日期：2026-07-28

## 行为

1. 用户进入发行中心后台（`DistributionLayout` token+member 就绪）后，若资料不完整则弹出强制弹窗。
2. 弹窗**不可关闭**（无关闭按钮、遮罩不可点关、Esc 无效）。
3. 必须上传头像 + 填写**英文昵称**后，点「完成，进入创作中心」提交。
4. 提交成功后关闭弹窗并刷新本地 `currentMember`。

## 资料完整判定

`profileComplete = 头像非空 && 昵称非默认 && 昵称符合英文规则`

- 默认昵称：空 / `LOL_User` / `LOL-{userId}` / 含 `****`
- 英文规则：2~50 字符，字母开头，仅 `A-Za-z0-9` 与空格 `.` `_` `'` `-`

## 接口

### GET `/publisher/member/me`（既有，扩展字段）

响应 `data` 新增：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `profileComplete` | boolean | 当前成员资料是否完整 |

### POST `/publisher/member/completeProfile`（新增）

- 鉴权：发行 token，**任意登录成员**可改**自己**
- Body：`{ "nickname": "CloudDrama", "avatar": "https://..." }`
- 成功 `data`：`{ nickname, avatar, profileComplete: true }`
- 失败码：
  - `403435` 昵称为空
  - `403436` 昵称非英文/超长
  - `403437` 头像为空

owner 提交成功时同步 `publisher_account` 品牌昵称/头像（`syncBrandFromUser`）。

### POST `/publisher/account/updateNickname`（行为变更）

账号页改品牌昵称同样强制英文规则（同上 403435/403436）。
