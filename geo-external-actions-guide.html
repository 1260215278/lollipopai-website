P1 建立 Wikidata 品牌词条

目标

在知识图谱中建立 "Lollipop Drama" 实体，消除与 Linux 音乐播放器 "Lollypop" 的搜索歧义。

操作步骤

1. 访问 wikidata.org，搜索 "Lollipop Drama" 确认无已有词条
2. 创建新 Item (Q-item)，填写：
• Label (en): Lollipop Drama
• Description (en): AI-powered short drama streaming platform
• Instance of (P31): software, mobile app, streaming platform
• Official website (P856): https://www.lollipop.im
• Developer (P178): Nyx Entertainment Group
• Operating system (P306): iOS, Android
• Inception (P571): 2026-07-08
• Headquarters (P159: Singapore
• Different from: Lollypop (Linux music player, Q ID needed)
3. 添加引用来源：EINPresswire 新闻稿链接、GlobeNewswire 链接
4. 确保 Wikipedia 文章可以引用此 Wikidata Item
Wikidata 条目是 AI 引擎（尤其是 ChatGPT）解析实体关系的重要数据源。

P2 获取 Schema.org sameAs 外部权威链接

目标

确保 Organization schema 中的 sameAs 链接（Twitter/Instagram/YouTube/TikTok/Facebook）有活跃内容和粉丝基础。

操作步骤

1. 检查以下社交账号的活跃度：
• Twitter: @lollipopai — 确保至少 1000+ 关注者，每周 3+ 推文
• Instagram: @lollipopai — 发布短剧截图、幕后花絮
• YouTube: @lollipopai — 上传官方预告片、创作者教程
• TikTok: @lollipopai — 发布短剧片段、AI 创作演示
• Facebook: @lollipopai — 社区互动、新闻发布
2. 在 Wikipedia 条目获得批准后，将 Wikipedia 链接添加到 sameAs 数组
3. 获取 Crunchbase 和 Product Hunt 页面，加入 sameAs
4. 更新 index.html 中的 sameAs 数组
AI 引擎使用 sameAs 链接验证品牌真实性和社交存在度。空壳社交账号会降低可信度。
