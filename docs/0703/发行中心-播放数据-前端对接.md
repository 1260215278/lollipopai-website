# 发行中心「播放数据」页 — 前端对接文档

- 日期：2026-07-03
- 后端分支：test
- 变更范围：`ranking` 每行**新增 `rankTrend`/`lastRank`**、响应**新增 `totalCount`**；`overview` 三个环比字段由整数改为**一位小数**（如 `23.4`）。无 DDL，老前端不受影响。

## 鉴权（三个接口相同）

- 请求头 `token`: **发行中心 token**（与控制台其它 `/publisher/**` 接口同一个，不是 App token）。
- 需要 `DASHBOARD_VIEW` 权限：超管/管理员默认有；员工按角色配置，且**只统计其被分配的剧**（未分配任何剧时各项为 0/空榜）。
- 错误码：`401181` 未带 token / `401182` token 无效或过期 / `403335` 无权限。

## 1. 顶部概览卡片

`GET /publisher/dashboard/overview` — 无参数。

`data` 字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `dramaTotal` | Integer | 上剧总数（审核通过的剧） |
| `dramaMonthAdd` | Integer | 本月新增部数 |
| `playTotal` | Long | 累计播放量 |
| `playMomRate` | Number | 播放量环比（本月 vs 上月，%，**一位小数**，可为负，如 `23.4` / `-5.0`） |
| `likeTotal` | Long | 累计点赞数 |
| `likeMomRate` | Number | 点赞环比，同上口径 |
| `collectTotal` | Long | 累计收藏数 |
| `collectMomRate` | Number | 收藏环比，同上口径 |
| `balanceUsd` / `yesterdayUsd` / `monthToDateUsd` | Number | 结算金额三件套，**仅超管/管理员返回**（员工无此三个 key，取不到时不要报错） |

环比展示规则：正数前端自行加 `+` 号；上月为 0 且本月有量时返回 `100.0`；两月都为 0 返回 `0.0`。

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "dramaTotal": 5,
    "dramaMonthAdd": 2,
    "playTotal": 3802000,
    "playMomRate": 23.4,
    "likeTotal": 138000,
    "likeMomRate": 18.7,
    "collectTotal": 76000,
    "collectMomRate": 15.2
  }
}
```

## 2. 数据趋势

`GET /publisher/dashboard/trend`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `metric` | String | 否 | `play` 播放（默认）/ `like` 点赞 / `collect` 收藏，对应三个 tab |
| `range` | Integer | 否 | `7` 近7天（默认）/ `30` 近30天 |

`data` 字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `metric` | String | 回显本次指标 |
| `total` | Long | 该指标区间内总量（图例"近7天播放 16,300"用这个） |
| `points` | Array | 按天补零的连续日期轴，`[{date:"06-04", value:1200}, ...]`，`date` 为 `MM-dd` |

- 图例要同时显示播放/点赞/收藏三个总数时，**按 metric 调 3 次**（每次只换 `metric`，取各自 `total`）。
- 播放数据由每日 **20:00** 的统计任务产出：**当天的点在 20:00 前恒为 0**，属正常现象，不是接口异常。

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "metric": "play",
    "total": 16300,
    "points": [
      { "date": "06-04", "value": 1200 },
      { "date": "06-05", "value": 1750 },
      { "date": "06-06", "value": 1680 }
    ]
  }
}
```

## 3. 剧集数据排行

`GET /publisher/dashboard/ranking`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `limit` | Integer | 否 | 返回条数，默认 10。首屏建议 5，「展开更多」后用更大的 limit 重新请求 |

`data` 字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `totalCount` | Integer | 该账户可见剧总数。「展开更多 (N 部)」的 N = `totalCount - 当前已展示条数` |
| `list` | Array | 按总播放量降序，字段见下 |

`list[]` 每项：

| 字段 | 类型 | 说明 |
|---|---|---|
| `rank` | Integer | 当前名次，从 1 开始 |
| `rankTrend` | Integer | **名次升降箭头**：`1` 上升（绿↗）/ `-1` 下降（红↘）/ `0` 持平或新上剧（不显示箭头） |
| `lastRank` | Integer | 上期名次，可为 `null`（新剧无历史快照），tooltip 可用 |
| `courseId` | Long | 剧 ID |
| `title` | String | 剧集名称 |
| `episodeCount` | Integer | 集数 |
| `playCount` | Long | 总播放量 |
| `likeCount` | Long | 点赞数 |
| `collectCount` | Long | 收藏数 |
| `commentCount` | Integer | 评论数 |
| `shareCount` | Integer | 分享数，**当前恒为 0**（分享埋点二期才有来源），列可先展示 0 或占位 `-` |

`rankTrend` 口径：与 **7 天前**的播放量快照重排出的名次对比（上线不足 7 天用最早一次快照；完全无快照记 `0`）。

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "totalCount": 7,
    "list": [
      {
        "rank": 1,
        "rankTrend": 1,
        "lastRank": 2,
        "courseId": 45,
        "title": "星河恋人",
        "episodeCount": 24,
        "playCount": 1482000,
        "likeCount": 32000,
        "collectCount": 18000,
        "commentCount": 4521,
        "shareCount": 0
      },
      {
        "rank": 2,
        "rankTrend": -1,
        "lastRank": 1,
        "courseId": 46,
        "title": "穿越千年寻你",
        "episodeCount": 36,
        "playCount": 926000,
        "likeCount": 21000,
        "collectCount": 12000,
        "commentCount": 2870,
        "shareCount": 0
      }
    ]
  }
}
```

## 联调注意

1. 页面顶部账号信息（`12****5674` / 角色名）不在本页三接口里，用已有的 `GET /publisher/member/me`。
2. 统计范围均为**审核通过**（`audit_status=2`）且未删除的剧；员工登录时再叠加"被分配剧集"过滤。
3. 环比字段从整数改为一位小数属**类型放宽**（`23` → `23.4`），老代码 `Number` 解析不受影响。
