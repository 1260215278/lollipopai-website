## 二、字段契约

### 2.1 入参（`POST /publisher/course/saveBasic`）

请求体在原有字段之后追加：

```jsonc
{
  "courseId": null,
  "titleImg": "...",
  "title": "...",
  "details": "...",
  "plannedEpisodes": 20,
  "genderType": 3,
  "languageType": "en",
  "courseLabel": "标签1,标签2",
  "copyrightType": 2,            // 1自制 / 2授权
  "copyrightProof": "https://oss.lollipop.im/.../授权书.pdf"  // 仅 copyrightType=2 时必填
}
```

服务端处理逻辑（`PublisherCourseServiceImpl.saveBasic`）：

```text
if copyrightType == 2:
    if copyrightProof 为空 → 报错 i18n key: publisher_course_copyright_proof_required
    else  → 入库 copyright_proof = <URL>
else (copyrightType == 1 或其它):
    强制 copyright_proof = null（即使前端误传也不入库）
```

错误响应示例：
```json
{ "code": 500, "msg": "选择授权时必须上传版权证明", "data": null }
```
（实际 `msg` 按当前 `Accept-Language` 渲染：en / zh / cht / pt 四语已齐。）

### 2.2 回显（`GET /publisher/course/draft` 与 `GET /publisher/course/detail`）

`data.basic` 节点（detail）或 `data.course` 节点（draft 旧字段位置）中新增：

```json
"copyrightProof": "https://oss.lollipop.im/.../授权书.pdf"
```

未设置时返回 `null`；前端 `DraftCourse` / `CourseDetailBasic` 类型已预留该字段，无需改 schema。

### 2.3 后管审核（`short-drama-vue`）

* **审核列表**（`PublisherCourseAuditServiceImpl.list`）返回行内字段新增 `copyrightProof`，便于一眼定位需要细看授权书的剧。
* **审核详情**（`PublisherCourseAuditServiceImpl.detail`）`data.basic` 内新增 `copyrightProof`，审核人点开后预览。

后管端建议显示：
- 若链接以 `.pdf` 结尾 → `<a href="..." target="_blank">查看授权书 (PDF)</a>` 直链下载
- 否则当图片 → `<img>` 缩略

## 三、上传端点

| 端点 | 鉴权 | 接受类型 | 大小档 |
|---|---|---|---|
| `POST /publisher/course/upload` | `@PublisherLogin` | 图片 / 视频 / **PDF** | 图 10MB / 视频 500MB / **文档 20MB** |

新加：扩展名白名单 `.pdf`，MIME 实际由扩展名分流，PDF 走 `MAX_DOC_SIZE=20MB`。

请求字段：`form-data` `file=<File>`，同其它上传一致。响应：

```json
{ "code": 0, "msg": "success", "data": "https://oss.lollipop.im/...授权书.pdf" }
```

前端 `accept` 建议：
- 选择「自制」(`copyrightType=1`) → 不显示上传控件
- 选择「授权」(`copyrightType=2`) → 显示控件，`accept="image/*,.pdf"`（PDF + 图片授权书都接受）
