## P0. 账号短信 `scene` 契约（补文档，无代码变更）

当前实现即为最终契约：

1. **`scene` 参数后端不校验、不区分场景**——可不传、传任意值均可，同一个验证码全场景通用（设置密码/开关两步验证/注销共用）。前端传建议表里的 `change_password` 等值也没问题，仅作埋点语义。
2. **验证码发到发行账户主账号（超管）手机号**，不是当前成员手机号。这是自洽的：`sendSmsCode`/`changePassword`/`twoFactor`/`cancel` 全部挂 `ACCOUNT_SETTING` 权限，而该权限**仅超管拥有**（管理员/员工调用直接被权限拦截）——所以"当前成员"必然就是主账号本人。
3. 错误码：

| 场景 | msg |
|---|---|
| 主账号无手机号 | `403336` |
| 发送过于频繁（60 秒内重复发） | `40034` |
| changePassword 校验不过（旧密码/短信码均不对，或新密码为空） | `403339` |
| 两步验证开/关短信码不对 | `403340` |
| 注销：未勾选确认 或 短信码不对 | `403340` |
| 注销：有待结算/可提现余额或进行中结算单 | `403341` |
| 注销：有审核中的剧 | `403342` |

4. 频控/有效期：同手机号 **60 秒 1 条**；验证码**一次性**（校验通过即作废）、有过期校验；重复发送**不覆盖**旧码（有效期内多个码均可用）。测试环境万能码 `763694`。
5. `passwordSet=true` 时短信码可替代旧密码：**已支持**——`oldPassword` 与 `smsCode` 二选一，先验旧密码，不对再验短信码。
