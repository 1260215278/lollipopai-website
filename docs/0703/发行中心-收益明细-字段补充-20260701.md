## 1. `GET /publisher/settlement/overview` 收益总览 — 新增/变更

| 字段 | 变化 | 说明 |
|---|---|---|
| `settlementBillCount` | **新增** | 结算账单数 = 该发行方 `publisher_settlement_record` 全状态、未删的条数（对应设计稿「结算账单 7」） |
| `monthlyTrend` | **变更** | 由「近 6 月、空月不返回」改为 **本年 1—12 月满 12 项、空月补 0**（前端可直接画整年，无需自补） |

`monthlyTrend` 新形态（始终 12 项，month 升序）：

```jsonc
"monthlyTrend": [
  { "month": "2026-01", "amountUsd": 0.00 },
  { "month": "2026-02", "amountUsd": 80.50 },
  // ... 一直到
  { "month": "2026-12", "amountUsd": 0.00 }
]
```

其余字段（`totalCumulativeUsd`/`withdrawableUsd`/`processingUsd`/`withdrawnUsd`/`pendingUsd`/`yesterdayUsd`/`estThisMonthUsd`/`growthRate`/`relatedDramas`/`currency`）不变，见 20260630 契约。

> 设计稿「本月预估」= `estThisMonthUsd`（本月至今已入账实得），非未来预测值。
> 币种仍为 `USD`；设计稿显示的 ¥ 属展示层，前端自行换算/换符号。

## 2. `GET /publisher/settlement/earnings` 收益明细 — 新增入参 + 行字段

### 2.1 新增入参

```
?page=1&limit=10&startDate=2026-06-01&endDate=2026-06-30&courseId=1024&keyword=星河
```

| 入参 | 说明 |
|---|---|
| `keyword` | **新增**，选填。按**剧名模糊搜索**（`course.title LIKE %keyword%`）。与 `courseId` 可并用。 |

「按月切换」用 `startDate/endDate` 传该月首末日即可。

### 2.2 每行新增字段

```jsonc
{
  "earnDate": "2026-06-29",
  "courseId": 1024,
  "courseTitle": "星河恋人",
  "courseImg": "https://oss.../cover.jpg",
  "publishScope": 2,
  "ratioLabel": "6:4",
  "ratio": 60,
  "orderCount": 12,
  "grossUsd": 50.00,
  "creatorUsd": 30.00,

  "viewCount": 1123000,   // ★新增 播放量。取自 course.view_counts（该剧累计播放量）
  "settleStatus": 1       // ★新增 结算状态：0待结算 / 1结算中 / 2已结算
}
```

**`settleStatus` 语义**（由覆盖该 `earnDate` 的结算单状态折算；一天落在结算单周期 `[period_start, period_end]` 内即取其状态）：

| settleStatus | 含义 | 来源结算单 status |
|---|---|---|
| `0` | 待结算（未进任何结算单，或结算单为草稿/驳回） | 无 / 0 / 4 |
| `1` | 结算中（已申请 / 审核通过待打款） | 1 或 2 |
| `2` | 已结算（已打款） | 3 |

> 前端文案自行渲染：`0→待结算`、`1→结算中`、`2→已结算`。
> 说明：`viewCount` 是**该剧累计播放量**（`course.view_counts`），非当日增量——同一剧的多日行会重复显示同一累计值。若后续要「当日播放量」需接入 watch 按日聚合，本期不做。

## 3. 前端切真提示

- overview：读 `data.settlementBillCount`；`monthlyTrend` 直接按 12 项渲染（不用再补空月）。
- earnings：行内多了 `viewCount` / `settleStatus`；搜索框走 `keyword` 入参。
- `growthRate` 仍可能为 `null`（上月为 0），展示防御为 "--"。
