## 0.1 通用约定

- 所有 `/publisher/**` 接口 header 带发行中心 token（`POST /publisher/login/byAppToken` 换取），header 名 `token`。**不要带 App token**。
- 写接口（upload/saveBasic/saveEpisode/deleteEpisode/saveHighlight/publish/shelf/clearDraft）需 COURSE_MANAGE 权限（超管/管理员）；读接口 DASHBOARD_VIEW（员工可看）。员工账号应按登录返回的角色隐藏写按钮。
- 响应结构注意：**list 的分页对象在顶层 `page`**（`{totalCount,pageSize,totalPage,currPage,list}`），其余接口在 `data`。
- 业务错误 `code=500`（upload 例外为 `-100`），`msg` 为 i18n key/码，已按请求语言翻译。

# 一、发行新剧列表页

## 1.1 顶部统计卡片（新增）

`GET /publisher/course/stats` 无参数。

```json
{ "code": 0, "data": { "total": 3, "onShelf": 2, "auditing": 1, "offShelf": 0 } }
```

| 字段 | 卡片 | 口径 |
|---|---|---|
| `total` | 总发行剧集 | 本账号所有非草稿剧（含已驳回、通过未上架） |
| `onShelf` | 已上架 | 审核通过 且 当前上架 |
| `auditing` | 审核中 | 待审 |
| `offShelf` | 已下架 | 审核通过 且 已下架 |

⚠️ 四数不是加和关系（差值=驳回+通过未上架），不要用减法推算。

## 1.2 列表

`GET /publisher/course/list`

| 参数 | 必填 | 说明 |
|---|---|---|
| `keyword` | 否 | 搜短剧名称/编号（编号支持带 `D` 前缀） |
| `auditStatus` | 否 | 1审核中/2已通过/3已驳回 |
| `shelfStatus` | 否 | **新增** 0通过未上架/1已上架/2已下架（隐含审核通过），**勿与 auditStatus 同传** |
| `page`/`limit` | 否 | 默认 1/10 |

卡片点击筛选：审核中→`auditStatus=1`；已上架→`shelfStatus=1`；已下架→`shelfStatus=2`；总发行→都不传。

列表项字段 → UI 列：

```json
{
  "courseId": 12345, "dramaNo": "D12345", "title": "星河恋人", "titleImg": "https://oss.x/cover.png",
  "plannedEpisodes": 30, "uploadedEpisodes": 28,      // "28/30集已上传"
  "genderType": 2,                                     // 1男频/2女频/3通用
  "languageType": "en",                                // 语言code，国旗/名称前端映射
  "publishScope": 2,                                   // 1账号主页/2全量推荐
  "auditStatus": 2, "auditRemark": null,               // 驳回原因仅auditStatus=3有值
  "shelfStatus": 1,                                    // null(未过审)→"—"；0未上架/1已上架/2已下架
  "copyrightType": 1,                                  // 1自制/2授权
  "revenue": { "publishScope": 2, "platformRatio": 40, "creatorRatio": 60, "revenueText": "全量推荐 4:6" },
  "createTime": "2026-01-05 10:00:00"
}
```

## 1.3 操作菜单

| 菜单项 | 出现条件 | 接口 |
|---|---|---|
| 查看详情 | 任何状态 | `GET /publisher/course/detail` |
| 剧集视频 | 任何状态 | `GET /publisher/course/episodes` |
| 下架 | `auditStatus=2 && shelfStatus=1` | `POST /publisher/course/shelf` body `{"courseId":12345,"onShelf":false}` |
| 重新上架 | `auditStatus=2 && shelfStatus∈{0,2}` | 同上 `"onShelf":true` |
| 审核中，暂不可操作 | `auditStatus=1` | 纯前端提示 |

- 下架确认弹窗为前端文案；`shelf` 成功返回 `{code:0}`，之后**同时刷新 list 和 stats**。
- 仅审核通过可上下架，否则报 `publisher_course_shelf_need_pass`。

# 二、上传短剧 Step1「短剧基本信息」

`POST /publisher/course/saveBasic`（courseId 空=新建草稿，非空=更新草稿）

| UI 项 | 字段 | 说明 |
|---|---|---|
| 封面 | `titleImg` | 先走 2.1 的 upload 拿 URL（图片 ≤10MB，jpg/jpeg/png/gif/bmp/webp/heic/heif） |
| 短剧名称 | `title` | 必填 |
| 剧情简介 | `details` | 必填；200 字上限由前端控制 |
| 集数 | `plannedEpisodes` | 必填；**选择后不可修改**（`publisher_course_episodes_locked`） |
| 频道 | `genderType` | 1男频/2女频/**3通用** |
| 标签 | `courseLabel` | 多选逗号分隔；候选 `GET /publisher/course/labels?languageType=<语言code>`，**切语言要重拉并清空已选** |
| 版权类型 | `copyrightType` | 1自制/2授权 |
| 授权合同 | `copyrightProof` | `copyrightType=2` 必填（`publisher_course_copyright_proof_required`），=1 后端强制清空；文件走 upload，**支持 PDF/图片/Word(.doc/.docx)**，文档≤20MB |
| 剧集语言 | `languageType` | 语言 code（zh/cht/en/vie/kor/jp/Hindi/pt），本就在 Step1 请求里，UI 挪位置不影响接口 |

草稿恢复黄条：`GET /publisher/course/draft`（`data=null` 表示无草稿）；清空重填：`POST /publisher/course/clearDraft?courseId=`（仅草稿态，物理删）。

# 三、Step2「上传剧集」

## 2.1 文件上传（全流程共用）

`POST /publisher/course/upload`（multipart，字段 `file`）→ `data` = OSS URL 字符串。

| 类型 | 白名单 | 上限 |
|---|---|---|
| 图片 | jpg/jpeg/png/gif/bmp/webp/heic/heif | 10MB（超限 403355） |
| 视频 | mp4/avi/mov/wmv/flv/mkv/webm/m4v | 500MB（超限 403353） |
| 文档 | pdf/doc/docx | 20MB（超限 403354） |

其他错误（`code=-100`）：403348 空文件 / 403349 非法文件名 / 403350 格式不支持 / 403352 存储失败。

## 2.2 单集落库（每行「选择文件」后）

`POST /publisher/course/saveEpisode`

```json
// 请求
{ "courseId": 12345, "episodeNo": 1, "title": "第1集标题",   // title 选填
  "videoUrl": "https://oss.x/a1b2c3.mov",                      // 2.1 返回的 URL
  "fileName": "6月14日.mov" }                                   // 新增：原始文件名，行内回显用

// 响应 data
{ "courseDetailsId": 90001, "episodeNo": 1,
  "videoSize": 52428800,      // 字节→"50MB"；可能null→"—"
  "videoDuration": 95,        // 秒→"01:35"；可能null→"—"
  "uploadStatus": 1 }
```

- **同集号重复提交=覆盖**（换文件/改标题都走它）；仅 videoUrl 变化才重转码。
- ⚠️ 覆盖时 `fileName`/`title` 传空**不会清旧值**（后端更新策略跳过空值），换视频必须随传新 fileName。
- `episodeNo` 范围 1..集数（`publisher_course_episode_no_range`）；仅草稿/驳回可写（`publisher_course_not_editable`）。
- 批量上传/模版导入 = **前端循环**本接口（无批量提交接口）；建议并发 2~3 路。

## 2.3 移除单集（行内×，新增）

`POST /publisher/course/deleteEpisode?courseId=12345&episodeNo=3` → `{code:0}`

- 物理删除，行回「待上传」；**幂等**（行不存在也成功）；仅草稿/驳回态。
- ×必须落后端：只在前端隐藏的话，草稿恢复会"复活"，且送审"需全部上传"校验会把它算进去。
- 仅换文件不用删，直接覆盖。

## 2.4 批量模版 / 进度 / 状态

- 模版下载：`GET /publisher/course/uploadTemplate?courseId=` → xlsx（集号/剧集标题/视频链接，按集数预生成）。**前端本地解析回填**，无后端导入接口；外链场景跳过 2.1 直接把链接当 videoUrl。
- 进度（0/234 已选、还需上传 N 集、全部剧集已就绪）：前端由 `draft.episodes` 里 `uploadStatus=1` 的行数 ÷ `plannedEpisodes` 计算。
- 状态列：该集号**无记录**=待上传；`uploadStatus=1`已上传；`=2`上传失败。
- 草稿恢复：`draft` 的 `episodes` 每行含 `{courseDetailsId, episodeNo, title, videoUrl, fileName, videoDuration, videoSize, uploadDate, uploadStatus}`（老数据 `fileName=null` → 退化显示"已上传"）。

# 四、Step3「发布配置」

## 4.1 发布范围两张卡片（新增接口，勿写死比例）

`GET /publisher/course/revenueOptions`

```json
{ "code": 0, "data": [
  { "publishScope": 1, "platformRatio": 20, "creatorRatio": 80, "revenueText": "账户主页 2:8" },
  { "publishScope": 2, "platformRatio": 40, "creatorRatio": 60, "revenueText": "全量推荐 4:6" } ] }
```

比例后管可调，卡片上「平台 x% / 出品方 y%」用返回值渲染；标题/说明前端本地 i18n。

## 4.2 高光时刻（本次改必填）

1. 传文件走 2.1（MP4/MOV ≤500MB，与 UI 文案一致）。
2. 挂载：`POST /publisher/course/saveHighlight`

```json
// 请求
{ "courseId": 12345, "videoUrl": "①的URL", "fileName": "6月14日.mov" }
// 响应 data
{ "courseId": 12345, "highlightVideoUrl": "...",
  "highlightFileName": "6月14日.mov", "highlightFileSize": 15728640, "highlightUploadTime": "2026-07-02 10:00:00" }
```

- 已上传态胶囊「文件名 + 大小 + 已上传」用响应/草稿里的三个 highlight 字段渲染；大小后端探测（可能 null→"—"）、时间后端记录，前端只传 fileName。
- 换视频=再调一次（fileName 随传）；`videoUrl` 传空串=移除（元数据一并清空）。草稿期可移除，**送审前必须有**。
- 草稿恢复：`draft` 的 `data.course.highlightVideoUrl/highlightFileName/highlightFileSize/highlightUploadTime`。

## 4.3 上架设置 + 提交发布

`POST /publisher/course/publish` body `{ "courseId":12345, "publishScope":2, "onShelfNow":true }`
→ `data { courseId, auditStatus:1 }`，剧进入审核中，跳回列表。

错误分支（按校验顺序）：

| msg | 场景 | 前端处理 |
|---|---|---|
| `publisher_course_not_submittable` | 非草稿/驳回态重复提交 | toast+刷新 |
| `publisher_course_basic_incomplete` | 基本信息不全 | 回 Step1 |
| `publisher_course_upload_all_first` | 剧集没传满 | 回 Step2 |
| `publisher_course_highlight_required` | **高光没传（新增）** | 定位高光块标红 |

⚠️ **发布范围与上架设置不入草稿**（publish 才落库），中途离开需前端自缓存；高光已入草稿。

## 4.4 收费规则弹窗

`GET /publisher/course/priceRule?episodes=<本剧集数>` → `data` 数组：
`{ country, countryName, episodePriceUsd, wholePriceLe50Usd, wholePriceGt50Usd, wholePriceUsd(传了episodes才有) }`
`episodePriceUsd` 为 null 渲染"—"。

# 五、短剧详情页 + 剧集视频管理页

## 5.1 详情

`GET /publisher/course/detail?courseId=` → `data`：

- 顶部：`title` + `auditStatus` 徽标 + `dramaNo`；驳回原因 `auditRemark`。
- `basic`：封面/简介/集数/频道/标签(逗号分隔)/版权/语言 + `createTime`(上传日期) + 高光四字段（见 4.2）。
- `progress`：`{ plannedEpisodes, uploadedEpisodes, failedEpisodes(新增), pendingEpisodes(新增), percent }` → 右侧进度卡三 chip。
- `publish`：`{ publishScope, shelfStatus }` → 发布配置卡徽标。
- `priceRule`：**「上架国家」没有独立字段**，就是这份启用计价国家列表，用 `country/countryName` 渲染国旗。
- `revenue`：收益方式卡。
- 「修改素材」= 4.2 流程、「继续上传剧集」回 Step2 —— 均仅草稿/驳回态，其他状态禁用。

## 5.2 剧集视频管理

`GET /publisher/course/episodes?courseId=&keyword=&page=&limit=` → `data`：
`{ courseId, title, plannedEpisodes, uploadedEpisodes, stat:{uploaded,failed,pending}, episodes:[…同 2.4 行结构] }`

- `keyword` 搜集数或标题；顶部三 chip 用 `stat`。
- 「重新上传」= 2.2 覆盖流程，**仅草稿/驳回态**；审核中/已通过报 `publisher_course_not_editable`，按钮按 `auditStatus` 禁用。
