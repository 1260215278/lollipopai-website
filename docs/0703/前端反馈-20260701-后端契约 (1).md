## 2. 批量录入模版下载（新增）

发行中心控制台「批量上传模版」按钮对接此接口，下载一份**按具体短剧生成**的 Excel 录入表（`.xlsx`），
列**对齐现有上剧字段**（集号 / 剧集标题 / 视频链接）。**用途是数据录入**：出品方下载→在 Excel 里逐集填标题与视频链接→
**前端本地解析这份 Excel，把值批量灌进上剧表单的输入框**（前端按集号自动排序）。**后端不参与解析/不做批量上传接口**——
后端只负责生成并下发这份模版。

### 2.1 接口

```
GET /sqx_fast/publisher/course/uploadTemplate?courseId={courseId}
鉴权：@PublisherLogin —— 请求头 token = publisher token（与其他 /publisher/** 一致）
响应：Excel 文件流（.xlsx），下载文件名 批量录入模版_D{courseId}.xlsx
```

### 2.2 前端调用要点

- **必须带 `token` 头**，因此不能用 `<a href>`/`window.open` 直链；用 XHR/fetch 以 `responseType: 'blob'` 拉取后另存（与后管其它 Excel 导出下载方式一致）。
- 参数 `courseId`：当前正在上剧/编辑的短剧 id。
- 成功 → 响应头 `Content-Disposition: attachment; filename=...`，内容为 xlsx blob。
- 失败 → 响应是 JSON（非 xlsx），前端按 `Content-Type` 判断：
  | 场景 | 返回 |
  |---|---|
  | 非本人短剧 / 短剧不存在 | `publisher_course_no_view` |
  | 未设置集数（planned_episodes 为空/0） | `publisher_course_need_episodes` |
- **解析与导入在前端完成**：读 Excel 三列 → 按「集号」升序排序 → 填进对应集的标题/视频链接输入框。视频链接为可播放的视频地址（mp4/mov/m4v 等）。

### 2.3 Excel 内容

- 首行合并标题（填写说明）：
  `批量录入模版：每行一集，填写「剧集标题」与「视频链接」（视频链接为可播放的视频地址，支持 mp4/mov/m4v 等）；「集号」按 1、2、3… 顺序填写，导入后按集号自动排序。`
- 数据列（**对齐现有上剧字段**）：

  | 集号 | 剧集标题 | 视频链接 |
  |---|---|---|
  | 1 | （该集已录入则回填，否则空） | （该集已录入则回填，否则空） |
  | … | … | … |
  | N | | |

- 「集号」预填 `1..N`（连续正整数=集号规则）；「剧集标题」「视频链接」按已录入的 `course_details` 回填（供编辑），未录入留空供填写。
- 前端导入后按「集号」自动排序。

## 3. 本剧高光时刻宣传视频上传（新增，选填）

上传完剧集后，出品方可为本剧上传**一个**「高光时刻宣传视频」（选填素材，**不阻断送审**）。存储直存原始视频 URL，前端直播 mp4，不转码。

### 3.1 两段式（与剧集上传一致）

1. **传文件**：`POST /sqx_fast/publisher/course/upload`（multipart `file`，视频 ≤500MB，`@PublisherLogin`）→ 响应 `data` 为视频 URL。
2. **挂载**：`POST /sqx_fast/publisher/course/saveHighlight`（`@PublisherLogin`）

```
POST /sqx_fast/publisher/course/saveHighlight
Header: token = publisher token
Body(JSON): { "courseId": 123, "videoUrl": "https://.../promo.mp4" }
```

- `courseId`：必填。
- `videoUrl`：**选填**。传 URL = 设置/替换；**传空串或不传 = 移除**已有宣传视频。
- 写入门槛：仅**草稿/驳回**态可写（与 saveBasic/saveEpisode 一致）。

成功返回：
```json
{ "code": 0, "msg": "success", "data": { "courseId": 123, "highlightVideoUrl": "https://.../promo.mp4" } }
```

失败：

| 场景 | 返回 |
|---|---|
| 非本人短剧 / 不存在 | `publisher_course_no_auth` |
| 非可写态（草稿/驳回之外） | `publisher_course_not_editable` |

### 3.2 回显

短剧详情 `GET /publisher/course/detail` 的 `data.basic.highlightVideoUrl`、草稿恢复 `GET /publisher/course/draft` 的 `data.course.highlightVideoUrl` 均会带出当前值（未设置为 `null`）。
