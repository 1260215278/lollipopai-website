# 发行中心 · 成员管理 + 账号信息 前端对接契约

- 日期：2026-07-01
- 域：出品方控制台 `/publisher/**`（发行 token；请求头 `token`）
- 规范：响应 `{code,msg,data}`，`code=0` 成功、`code=500` 业务失败（`msg` 为对应文案）
- 权限：登录态由发行 token 决定角色；无权接口返回 `code=500`、`msg`=`403335`（无该操作权限）
- 相关：`docs/superpowers/specs/2026-07-01-publisher-member-account-design.md`

---

## 0. 登录 / 会话变化（重要）

- `POST /publisher/login/byAppToken?appToken=<App token>` 不变，但**换 token 条件从「is_publisher=1」改为「该用户存在启用中的成员身份」**（超管或被添加的成员都能进）。返回 `data`=发行 token（内嵌会话，支持踢下线）。
- 发行 token 失效新增场景：会话被「单设备下线 / 退出所有设备 / 移除成员 / 注销账号」置下线后，接口返回 `401` 语义、`msg`=`403343`（会话不存在或已下线，请重新登录）→ 前端跳登录。

## 1. 成员管理 `/publisher/member/*`（仅超管）

### GET `/publisher/member/list` — 成员列表
`data`: 数组，元素：
```
{ memberUserId, nickname, avatar, phoneMask, role(1超管/2管理员/3员工), roleName,
  status(1使用中/0停用), statusName, self(boolean), removable(boolean), joinTime }
```
超管置顶；`removable=false` 表示不可移除（超管或本人）。

### POST `/publisher/member/add` — 添加成员
请求：`{ phone, role }`（role 仅 2/3）。错误码：`403331` 角色非法 / `403328` 手机号未注册 / `403329` 已是本账户成员 / `403330` 已属其他发行账户。

### POST `/publisher/member/updateRole` — 改角色
请求：`{ memberUserId, role(2|3) }`。错误码：`403334` 不存在 / `403332` 不能改超管 / `403331` 角色非法。

### POST `/publisher/member/remove` — 移除成员
请求：`{ memberUserId }`。错误码：`403332` 不能移除超管 / `403333` 不能移除本人 / `403334` 不存在。成功后该成员被踢下线、剧目分配清空。

### GET `/publisher/member/roles` — 角色权限说明（任意登录成员）
`data`: 3 张角色卡片，驱动「角色权限说明」区与「添加账号」下拉（下拉取 `addable=true`）：
```
[{ code, name, description, addable, permissions:[{ key, name, allowed }] }]
```

## 2. 员工分配剧目 `/publisher/member/course/*`（超管/管理员）

- GET `/publisher/member/course/list?memberUserId=` → `data:{ assignedCourseIds:[], pool:[{courseId,title,titleImg,auditStatus}] }`
- POST `/publisher/member/course/assign` — `{ memberUserId, courseIds:[] }` 覆盖式；错误码 `403345` 非员工 / `403344` 剧目不属本账户
- POST `/publisher/member/course/unassign` — `{ memberUserId, courseIds:[] }`

> 员工登录后，`/publisher/dashboard/*` 与 `/publisher/course/list|detail` 仅返回其被分配的剧目；员工的数据概览不含结算金额字段。

## 3. 账号信息 `/publisher/account/*`（仅超管）

| 接口 | 方法 | 请求 | 说明 |
|---|---|---|---|
| `/info` | GET | — | 聚合：`profile{accountCode,nickname,avatar,certified,registerTime,lastLoginTime}` / `contact{phoneMask,phoneBound,emailMask,emailBound}` / `security{passwordSet,twoFactorEnabled,securityLevel(1低2中3高)}` / `notify{notifyEmail,notifySms}` |
| `/updateNickname` | POST | `{nickname}` | 改剧方昵称 |
| `/updateAvatar` | POST | `{avatar}` | URL 来自 `POST /alioss/upload` |
| `/notify` | POST | `{notifyEmail,notifySms}` | 通知开关（1/0） |
| `/sendSmsCode` | GET | `?scene=` | 发码到绑定手机 |
| `/sendEmailCode` | GET | `?email=` | 发码到目标邮箱 |
| `/bindEmail` | POST | `{email,code}` | 绑定/换绑；错误码 `403337` 码错 / `403338` 邮箱占用 |
| `/changePassword` | POST | `{oldPassword?,smsCode?,newPassword}` | 已设密码需原密码或短信码；未设密码走短信设置。错误码 `403339`/`403336`。**注意：与 App 登录同一密码** |
| `/twoFactor/enable` `/twoFactor/disable` | POST | `{smsCode}` | 两步验证开关；码错 `403340` |
| `/sessions` | GET | — | `[{sessionId,device,ipMask,location,loginTime,lastActiveTime,current,online}]` |
| `/sessions/kick` | POST | `{sessionId}` | 单设备下线；`403343` 不存在 |
| `/sessions/logoutAll` | POST | `{}` | 退出所有设备（当前成员） |
| `/logout` | POST | — | 退出当前会话 |
| `/cancel` | POST | `{confirm:true, smsCode}` | 注销发行账号；**需 confirm + 短信再鉴权**（缺失=`403340`）；守卫 `403341` 有待结算/余额 / `403342` 有审核中剧 |

## 5. ⚠️ 后管前端需同步（迁移影响）

旧表 `publisher_user_id` 已全量迁 `account_id`。**后管两处入参字段名改动**：
- `GET /admin/publisher/earnings/list`：查询参数 `publisherUserId` → `accountId`
- `POST /admin/publisher/settlement/generate`：请求体 `publisherUserId` → `accountId`

值改为「出品方账户 id（publisher_account.id）」，不再是 tb_user.user_id。
